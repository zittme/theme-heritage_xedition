# Heritage XEDITION (헤리티지 XEDITION)

[Zittme](https://github.com/zittme/zittme) 엔진용 공식 테마입니다. [헤리티지](https://github.com/zittme/theme-heritage_default) 테마를 기반으로 XE 시절 XEDITION 레이아웃의 디자인을 되살렸습니다. 골드 포인트 컬러와 다크 그레이 조합, 클래식 테이블형 게시판 등 XEDITION 특유의 무드를 현재 코드 기준(템플릿 v2 · 반응형 · 다크 모드)으로 재해석했습니다.

- 데모: https://heritage-xedition.zitt.me
- 스토어: https://zitt.me/store/package/32473

## 요구 사항

- Zittme 1.0.0 이상
- 커머스 · 예약 · 짓미페이 · 문의 · 지식질문 · 쪽지 스킨은 해당 모듈이 설치된 사이트에서만 적용됩니다. 커머스 스킨은 [commerce](https://github.com/zittme/commerce) 0.2.17 이상에 맞춰져 있습니다.

## 설치

Zittme 설치 경로의 `themes/heritage_xedition` 에 이 저장소의 내용을 놓습니다. **폴더 이름은 `heritage_xedition`** 입니다.

```bash
cd 설치경로/themes
git clone https://github.com/zittme/theme-heritage_xedition.git heritage_xedition
```

압축 파일로 받았다면 `themes/heritage_xedition/` 에 풀면 됩니다. 이후 관리자 > 테마에서 헤리티지 XEDITION 을 적용하면 레이아웃과 스킨이 한 번에 바뀝니다.

## 구성

- 레이아웃 `heritage_xedition`: 한 줄 헤더와 메뉴별 다크 드롭다운, 풀폭 비주얼 슬라이더, 서브 타이틀 밴드, 다크 카피라이트 바
- 모듈 스킨 `heritage_xedition`: 게시판 · 회원 · 쪽지 · 커머스 · 예약 · 짓미페이 · 문의 · 지식질문
- 커머스 스킨: 안내문 HTML, 배너 포인트 이미지 정렬, 주문내역·장바구니 링크와 검색창 표시 설정, 주문 상태 필터를 지원합니다
